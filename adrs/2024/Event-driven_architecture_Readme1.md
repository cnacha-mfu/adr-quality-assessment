# Event-driven architecture
### Title
Adopting Event-driven Architecture for Real-time Data Processing

### Context
Our current system architecture struggles to handle the increasing volume of real-time data generated by our IoT devices. The traditional request-response model is becoming inadequate for processing this data efficiently, leading to delays in data processing and analysis.

### Decision
We propose adopting an event-driven architecture to improve the scalability and responsiveness of our system.

### Rationale
Event-driven architecture allows us to process data as it arrives, rather than waiting for requests. By decoupling components and leveraging asynchronous communication through events, we can handle high volumes of data in real-time. This approach enables parallel processing and ensures timely delivery of insights to stakeholders.

### Consequences
#### Pros:

- Real-time Processing: Enables immediate processing of incoming data.
- Scalability: Can handle large volumes of data without performance degradation.
- Responsiveness: Provides timely insights and actions based on incoming events.
- Flexibility: Supports dynamic changes in data sources and processing requirements.
#### Cons:

- Complexity: Managing event flows and ensuring data consistency may introduce complexity.
- Operational Overhead: Monitoring and managing distributed systems require additional effort.
- Learning Curve: Team members may require training to adapt to the event-driven paradigm.

### Sample Code
###### Example of publishing an event
-------------------------------------------
const { Kafka } = require('kafkajs');

const kafka = new Kafka({
  brokers: ['localhost:9092']
});

const producer = kafka.producer();

// Publish an event
async function publishEvent(topic, event) {
  await producer.send({
    topic: topic,
    messages: [
      { value: JSON.stringify(event) }
    ]
  });
}

// Example of consuming an event
const consumer = kafka.consumer({ groupId: 'my-group' });

// Consume events
async function consumeEvents() {
  await consumer.connect();
  await consumer.subscribe({ topic: 'my-topic', fromBeginning: true });

  await consumer.run({
    eachMessage: async ({ topic, partition, message }) => {
      console.log(`Received message ${message.value} from topic ${topic}`);
      // Process the event
    }
  });
}

consumeEvents();
